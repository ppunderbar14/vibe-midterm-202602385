## 앱 소개

고객이 음료와 옵션을 골라 주문하고 관리자가 주문 내역·제조 상태·재고를 확인하는 단일 페이지 웹앱이다. HTML/CSS/바닐라 JavaScript만 사용하며 빌드, 외부 API, 유료 서비스 없이 GitHub Pages에서 동작하도록 구현할 예정이다.

| 메뉴 | 가격 | 초기 재고 |
| --- | ---: | ---: |
| 아메리카노 | 3,000원 | 20잔 |
| 카페라떼 | 3,500원 | 15잔 |
| 바닐라라떼 | 4,000원 | 15잔 |
| 카페모카 | 4,500원 | 10잔 |
| 초코라떼 | 4,000원 | 10잔 |

모든 메뉴에 샷 추가(+500원), 시럽 추가(+0원)를 각각 선택할 수 있다. 같은 메뉴라도 옵션이 다르면 별도 장바구니 항목으로 처리한다.

## 사용법 초안

### 고객

1. 고객 화면에서 메뉴와 남은 재고를 확인한다.
2. 샷·시럽 옵션을 선택하고 장바구니에 담는다.
3. 수량을 수정하거나 항목을 삭제하고 총액을 확인한다.
4. 주문 확정을 누른다. 전체 재고 검증과 저장에 성공하면 재고가 한 번 차감되고 장바구니가 비워진다.
5. 주문 확인 영역에서 주문번호·주문 시각·확정 내역·총액·제조 상태를 확인한다.

품절 메뉴는 담을 수 없다. 재고가 부족하면 주문 전체를 차단한다. 장바구니에 담는 시점에는 재고를 차감하지 않는다.

### 관리자

1. 같은 페이지의 관리자 화면 버튼을 누른다.
2. 접수 주문과 메뉴별 남은 재고를 확인한다.
3. 제조가 끝난 주문의 제조 완료 버튼을 누른다. 상태만 변경되며 재고를 다시 차감하지 않는다.

이 화면은 시험용이며 실제 로그인·인증 기능은 없다.

### 저장과 복원

- 재고·장바구니·주문·다음 주문번호는 localStorage에 저장하고 새로고침 후 복원한다.
- 저장 데이터가 없는 첫 실행에만 초기 재고를 적용한다. 새로고침으로 재고가 다시 채워지지 않는다.
- 저장 실패나 손상된 데이터는 오류를 표시하며 성공으로 처리하거나 자동 덮어쓰기하지 않는다.
- 같은 브라우저의 같은 사이트 저장소를 사용한다. 브라우저 데이터를 삭제하면 기록이 사라질 수 있고, 로컬 주소와 Pages 주소의 데이터는 공유되지 않는다.
- 기본 사용 범위는 단일 탭이다. 다른 기기와 동기화하거나 여러 탭의 동시 주문을 완전히 보장하지 않는다.
